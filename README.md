# Indie Space: HTML & CSS Practice Project

A static space-news landing page built as an internship learning assignment using **HTML and CSS**.

The page combines a lead story, article cards, newest/trending stories and a video-style content section. It is a layout exercise using checked-in image and icon assets, not a live news service.

## What this repository demonstrates

- Structuring a long editorial-style page with HTML.
- Styling navigation, story cards and multi-section layouts with CSS.
- Organizing local images, icons and font references.
- Working from an internship assignment/template and maintaining the result in Git.

## Run locally

Open `index.html` in a browser, or serve the repository with Python:

```sh
python -m http.server 8000
```

Then open `http://localhost:8000`.

No package installation or build step is required.

## Structure

```text
index.html        # Static page content
style.css         # Page styling
assets/
  images/
  icons/
  fonts/
```

## Scope and attribution

This is an early learning project based on the supplied internship assignment/template. The repository's article text and imagery are static sample content, not current reporting or an original publishing product. There is no JavaScript application, backend, CMS or live news API.

The repository does not add new rights to third-party assets. Check the original asset permissions before reusing them.
